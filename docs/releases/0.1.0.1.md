# TGPulse-Next 0.1.0.1

## Highlights

- NetMerc advanced I/O, factory SRAM initialization and persistent calibration,
  serial tracking endpoint and standalone state integration.
- NetMerc finite TGP arithmetic compatibility path prevents the persistent City
  entry freeze. City Workaround defaults On for correct road-plane geometry;
  Off remains selectable. Other games retain their prior arithmetic policy.
- MVD Auto/Off/Right Stick/Sensors, SDL3 gyro calibration/recenter, optional
  accelerometer gravity stabilization (default On), assignable virtual controls
  and Auto/Manual Holder behavior with status/calibration notifications.
- Diagnostic LCD Off/Overlay/Dedicated Window, four corners, background opacity,
  HD44780 dot rendering with game ZIP/adjacent BIOS/Text fallback. Fullscreen
  switches to overlay without losing the window preference.
- NetMerc donor and procedural substitute audio, optional alternative gains,
  and pad rumble from the real trigger/thumb motor output, not LCD data.
- Library Board filter, rumble intensity controls and corrected auxiliary-window
  fullscreen/scissor render-target sizing.

## Verification And Limits

The local offline workspace suite passes 539 tests and the macOS ARM64
development release builds. A 1,800-frame before/after comparison on six Model 1
games and one representative per Model 2 revision matches serialized state and
PCM hashes. Both supplied pre-City states continue with City Off/On.
These bounded checks are not complete hardware-fidelity certification.

User acceptance closes MVD tracking, diagnostic LCD, NetMerc pad rumble and
substitute audio, and confirms City road geometry with the workaround enabled.
Extended later-level and repeat-game validation remains open. Audio recovery is
best effort, not an authentic reconstruction of missing ROM content. A verified
corrected dump and low-level Polhemus emulation remain possible future work.
Yaw tracking remains relative; XYZ translation is not tracked. COMM-fitted
Model 1 save states remain unsupported.

## Desktop Packages

GitHub Actions builds/tests macOS ARM64, Linux x86_64 and Windows x86_64, then
publishes archives and `SHA256SUMS`. macOS bundles SDL3 and uses Metal; its
ad-hoc signature is not Apple notarization. Packages contain project and
third-party license notices. ROMs, BIOS dumps, personal settings, NVRAM and
save states are never included. Android is not part of this release matrix.

Existing explicit configuration choices are preserved. City Workaround and
MVD Gravity Stabilization default On for new profiles or Restore Defaults;
stored Off values are not overwritten.
